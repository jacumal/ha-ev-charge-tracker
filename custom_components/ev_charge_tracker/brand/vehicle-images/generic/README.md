# Imágenes genéricas

Esta carpeta contiene las ilustraciones genéricas que se usan cuando el usuario no quiere mostrar un modelo concreto o el catálogo no dispone de imagen propia.

Archivo principal previsto: `vehicle-generic.png`.

Formato: PNG RGBA, 1200 × 675 px, fondo transparente y orientación frontal tres cuartos con el morro hacia la izquierda.
