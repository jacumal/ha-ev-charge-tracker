# BEV — Battery Electric Vehicles

Sube aquí un PNG por cada vehículo 100 % eléctrico.

Nombre: `<vehicle_id>.png`, usando el ID exacto de `vehicle_catalog.json`.

Ejemplos: `leapmotor-b10.png`, `byd-dolphin.png`, `xiaomi-su7.png`.

Consulta las especificaciones y condiciones de uso en el README de `../`.
