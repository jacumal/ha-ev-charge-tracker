# ChargeTrack brand identity

## Product identity
- **Name:** ChargeTrack
- **Descriptor:** EV Management Platform
- **Positioning:** a complete EV management platform for Home Assistant.
- **Mark:** minimalist open circular arc with a central lightning bolt. The open arc represents continuous tracking and the bolt represents electric mobility.

## Color system
| Token | Hex | Role |
|---|---|---|
| Brand blue | `#0A84FF` | Primary brand, links and selected data |
| Supporting cyan | `#32ADE6` | Secondary accent |
| Energy green | `#30D158` | Charging, battery and positive states |
| White | `#FFFFFF` | Light surfaces |
| System gray 6 | `#F2F2F7` | Light background |
| System gray | `#8E8E93` | Secondary labels |
| Secondary text | `#636366` | Muted text |
| Primary dark | `#1C1C1E` | Primary text |
| Dark navy | `#071B2D` | Dark brand surface |

## Usage
- Use the dark app icon on dark backgrounds and the light icon on light backgrounds.
- Keep the symbol free of text at small sizes.
- Use blue as the dominant interface accent; reserve green for active charging, battery and positive states.
- Prefer white and neutral gray surfaces, subtle borders and restrained gradients.
- The UI must follow Home Assistant's active light/dark theme rather than forcing one theme.
- Avoid rainbow accents, excessive glow and saturated full-card gradients.

## Stable technical identifiers
The Home Assistant domain `ev_charge_tracker`, Lovelace element type `ev-charge-tracker-card`, resource URL and existing entity IDs remain unchanged. The rebrand changes only user-facing naming and brand assets; it must not require deleting/recreating config entries or history.
